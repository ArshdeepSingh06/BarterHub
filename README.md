# BarterHub

A community-driven platform for exchanging items and services without money.

## What it does

- Discover listings from the community
- Post items or services you can offer
- Say what you would like in exchange
- Save interesting listings to your Buy list

## Built with

- Python
- Streamlit
- SQLite
- pytest

## Run locally

1. Install Python.
2. Install the project packages:

   ```bash
   python -m pip install -r requirements.txt
